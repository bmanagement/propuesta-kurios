Propuesta preparada para Kurios Colombia · 2026

De Inactiva
a Operativa

Acompañamos a Kurios Colombia desde el primer día, asegurando una transición ordenada desde su estado de inactividad hasta el inicio de una operación contable activa.

Este servicio integral, estructurado en dos fases, garantiza continuidad y cumplimiento en cada etapa.

Cómo Funciona

Dos Componentes, Un Flujo

El servicio sigue una secuencia clara: un setup inicial para construir la base, seguido de un servicio mensual recurrente una vez inicien las operaciones.

01
Único · 2026
Setup & Cobertura Dormancia
El servicio abarca la configuración inicial del área contable, incluyendo la definición de políticas, sistemas y procesos, así como el mantenimiento operativo durante la etapa de inactividad.

Su objetivo es establecer una estructura financiera sólida, profesional y en pleno cumplimiento desde el primer momento.

Este servicio se factura una única vez al inicio.
→
02
Transición · 2026
Primeras Operaciones
Si la compañía comienza a operar en 2026, el servicio contable recurrente se activa con una tarifa preferencial: 40% de la tarifa estándar del tier seleccionado para 2027.

Pagas únicamente cuando comienzas a operar.
→
03
Recurrente · 2027+
Servicio Contable Completo
A partir de enero de 2027, el servicio mensual se presta a tarifa completa.
El alcance y la tarifa se revisan anualmente, y el tier seleccionado define el nivel de servicio recurrente.
Un flujo: El setup prepara la base para cualquier tier. El tier que elijas define la profundidad de tu servicio mensual recurrente.
Protección de dormancia: Mientras la compañía esté inactiva (2026), todas las obligaciones fiscales, regulatorias y de cumplimiento se gestionan como parte del setup — sin costos mensuales adicionales.
